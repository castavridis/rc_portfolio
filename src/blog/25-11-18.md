# Creating a PR for @react-three/rapier

1. Create a fork of `https://github.com/pmndrs/react-three-rapier`
2. Download `react-three-rapier` to local folder
3. `@react-three/fiber` uses `yarn`, run `yarn`
  * Can install `yarn` with `npm install -g yarn`
3. In sample repository, update `package.json`:
  * Change `"@react-three/rapier": "^2.1.0"`
  * to "@react-three/rapier": "https://github.com/castavridis/react-three-rapier.git"

I ended up relying on Claude Code to help me figure out an approach to linking
`@react-three/rapier` with my local fork.

```
  Claude Code output:
  ---

  What was done:
  1. ✓ Built your fork at ~/Git/react-three-rapier/
  2. ✓ Linked it to your portfolio using the file: protocol
  3. ✓ Created symlink: node_modules/@react-three/rapier → your local fork

  Your package.json now has:
  "@react-three/rapier": "file:../react-three-rapier/packages/react-three-rapier"

  When you make changes to your fork:
  cd ~/Git/react-three-rapier/
  yarn build  # Rebuild after changes

  The changes will be immediately available in your portfolio project. No need to reinstall!
```
